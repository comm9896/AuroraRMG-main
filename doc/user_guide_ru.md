# Руководство пользователя AuroraRMG (CommFork)

## Обзор интерфейса

Главное окно разделено на вкладки:

### Вкладка «Simple Mode» (Быстрая генерация)
- Выбор режима игры (FFA, Duel, PvE, Team, Lanes)
- Количество игроков (2–8)
- Размер карты (Small, Medium, Large, Huge, Experimental)
- Длина игры (Short, Medium, Long)
- Сложность/хаотичность (Tame, Normal, Wild)
- Сила нейтралов и пограничной охраны
- Дополнительно: вода, порталы, границы
- Кнопка «Сгенерировать» — создаёт шаблон и открывает визуальный редактор

### Вкладка «Advanced» (Расширенные настройки)
- **Топология**: Ring, Balanced, Hub & Spoke, Chain, Lanes, Random
- **Размер карты**: точный выбор из списка (64–512)
- **Террейн**: FactionBased, Grass, Snow, Lava, Sand, Dirt, Deathland, Autumn, Random
- **Герои**: минимум, максимум, инкремент, запрет найма
- **Зоны**: количество нейтралов, замков, плотность ресурсов/построек
- **Условия победы**: Classic, City Hold, Tournament, Final Battle, Capital Hold
- **Вода, порталы, охрана, агрессия монстров, дипломатия**

### Вкладка «Ban Lists» (Запреты)
- Запрет предметов, магии, героев для всей карты

### Вкладка «Bonuses» (Бонусы)
- Стартовые бонусы: предметы, заклинания, характеристики, юниты, ресурсы

### Вкладка «Presets» (Пресеты)
- 35+ готовых конфигураций для быстрой игры:
  - 1v1 Классика (Дуэль, Стандарт, Хаб, Цепь, и др.)
  - 1v1 Один герой (Блиц, Дуэль, Эпопея, Хаб)
  - FFA (3–8 игроков)
  - ПвЕ (1 против 2–7 компьютеров)
  - Специальные (Король горы, Бойня)

### Вкладка «Content Pools» (Пулы контента)
- Просмотр и управление пулами контента
- Создание новых пулов
- Просмотр содержимого пулов (списки объектов, SID, веса)

## Быстрая генерация (Simple Mode)

Simple Mode — самый простой способ создать играбельный шаблон.

### Основные параметры

1. **Game Type** — определите режим:
   - **FFA** — каждый сам за себя
   - **Duel** — 1v1 без прямых соединений между игроками
   - **PvE** — один игрок против компьютеров
   - **Team** — командная игра (чётное количество)
   - **Lanes** — коридорная карта (каждый игрок в своей полосе)

2. **Players** — количество игроков (2–8)

3. **Map Scale** — размер карты:
   - Small — 64–96
   - Medium — 112–160
   - Large — 176–240
   - Huge — 256–400 (экспериментальный)

4. **Game Length** — влияет на количество нейтралов и плотность:
   - Short — быстрая игра
   - Medium — стандарт
   - Long — эпическая партия

5. **Chaos** — хаотичность:
   - Tame — предсказуемая карта
   - Normal — сбалансированная
   - Wild — сюрпризы и случайности

6. **Neutrals** — сила нейтральных монстров:
   - Weak — слабые
   - Normal — стандартные
   - Strong — сильные
   - Fortress — очень сильные
   - Impassable — непроходимые (экстремальные)

### Seed (Сид)

Каждый шаблон в Simple Mode генерируется из сида — числа, которое определяет все случайные параметры. Одинаковый сид + одинаковые настройки = одинаковый шаблон. Это позволяет делиться шаблонами с друзьями (название шаблона содержит сид, например "Quick FFA 3A1B2C3D").

## Расширенные настройки (Advanced)

### Топология карты

| Тип | Описание |
|-----|----------|
| **Ring** (Кольцо) | Игроки по кольцу, нейтралы внутри |
| **Balanced** (Сбалансированная) | Зоны разных типов равномерно распределены |
| **Hub & Spoke** (Хаб) | Все зоны вокруг центрального хаба |
| **Chain** (Цепь) | Линейная карта от игрока к игроку |
| **Lanes** (Коридоры) | Каждый игрок в своей полосе |
| **Random** | Случайная топология |

### Параметры зон

- **Player Zone Castles** — количество замков в стартовой зоне игрока
- **Neutral Zone Castles** — замки в нейтральных зонах
- **Resource Density** — плотность ресурсов (50–200%)
- **Structure Density** — плотность построек (50–200%)
- **Neutral Stack Strength** — сила нейтральных стражей (50–300%)
- **Border Guard Strength** — сила охраны на границах зон

### Условия победы

| Условие | Описание |
|---------|----------|
| **Стандартные** | Классическое уничтожение всех врагов |
| **Удержание города** | Удерживать нейтральный город N дней |
| **Турнир** | Серия битв по очкам |
| **Решающая битва** | Одна битва всех против всех |
| **Удержание столицы** | Захватить и удержать вражескую столицу |

## Визуальный редактор зон

Визуальный редактор — основное нововведение CommFork. Позволяет редактировать шаблон как граф: зоны — узлы, связи — рёбра.

### Панель инструментов

| Кнопка | Описание |
|--------|----------|
| 💾 **Сохранить** | Сохранить шаблон в .rmg.json |
| 📁 **Открыть** | Загрузить существующий шаблон |
| ➕ **Добавить зону** | Создать новую зону |
| ❌ **Удалить** | Удалить выбранную зону |
| 🔗 **Создать связь** | Создать связь между двумя зонами |
| 📋 **Менеджер связей** | Открыть таблицу всех связей |
| 🔄 **Макет и границы** | Настройка ориентации и границ |
| 📄 **JSON** | Просмотр/редактирование JSON шаблона |
| 🪞 **Зеркало** | Включить режим зеркального создания |
| © **Копировать зону** | Скопировать выбранную зону (Ctrl+C) |
| 📌 **Вставить зону** | Вставить скопированную зону (Ctrl+V) |
| ❓ **Справка** | Открыть справку по функциям редактора |

### Работа с зонами

- **Перетаскивание** — перемещайте зоны мышью
- **Выбор** — кликните на зону, чтобы открыть её свойства
- **Создание** — нажмите «Добавить зону» и укажите позицию
- **Копирование/вставка** — Ctrl+C / Ctrl+V (с проверкой конфликтов владельцев)

### Инспектор свойств зоны

При выборе зоны справа открывается панель свойств:

1. **Основные** — имя, размер, layout
2. **Биомы** — zoneBiome, contentBiome, metaObjectsBiome
3. **Главные объекты** — City, Spawn, AbandonedOutpost, GladiatorArena
4. **Главные объекты (дополнительные)** — дополнительные города/спавны
5. **Охрана** — guardCutoffValue, guardRandomization, guardMultiplier
6. **Контент** — пулы контента (guarded, unguarded, resources)
7. **Дороги** — связи между главными объектами
8. **Пул контента** — выбор пулов для зоны

### Типы зон (Layout)

| Тип | Цвет | Описание |
|-----|------|----------|
| Spawn (player) | 🟢 Зелёный | Стартовая зона игрока |
| Spawn (AI) | 🟢 Зелёный | Стартовая зона AI |
| Sides (Bronze) | 🟤 Коричневый | Бронзовые/боковые зоны |
| Treasure (Silver) | ⚪ Серый | Серебряные сокровищницы |
| Super Treasure (Gold) | 🟡 Золотой | Золотые сокровищницы |
| Center (Gold) | 🟡 Золотой | Центральная зона |
| Start Zone | 🔵 Синий | Нейтральная стартовая |
| Back Zone | 🟣 Фиолетовый | Тыловая зона |
| Leaf Zone | 🟢 Зелёный | Листовая зона |
| Win Condition | 🟠 Оранжевый | Зона условия победы |

### Работа со связями

**Создание связи:**
1. Выберите первую зону
2. Нажмите «Создать связь»
3. Выберите вторую зону

**Типы связей:**

| Тип | Цвет | Описание |
|-----|------|----------|
| **Direct** | Золотая сплошная | Прямое соединение (сразу видны) |
| **Proximity** | Зелёная пунктирная | Сближение (появляются при приближении) |
| **Portal** | Голубая штриховая | Портал между зонами |
| **Gladiator** | Красная штрих-пунктир | Арена гладиаторов |
| **Road** | Коричневая | Дорога (флаг Road=true) |

**Менеджер связей:**
- Таблица всех связей с номерами
- Двойной клик — открыть редактор связи
- Удаление связи через кнопку в таблице
- Fan-out рёбер — линии не накладываются

### Настройка связи

- **Имя** — уникальное имя связи
- **Тип** — Direct, Proximity, Portal, Gladiator
- **Guard Value** — сила охраны на связи
- **Road** — флаг дороги
- **Guard Match Group** — группа сопоставления охраны
- **Sim Turn Squad** — отряд симуляции хода
- **Length** — длина (только для Proximity)

### Режим зеркального создания

Позволяет создавать симметричные карты:

1. Нажмите кнопку «Зеркало»
2. В появившемся диалоге включите зеркальный режим
3. Выберите опции:
   - **Отзеркаливание свойств** — изменения свойств зоны копируются на зеркальную
   - **Отзеркаливание соединений** — связи между зонами дублируются для зеркальных пар
4. Вертикальная золотая линия разделяет холст пополам
5. Все новые зоны создаются парами

### JSON Preview

Позволяет просматривать и редактировать шаблон напрямую в JSON:

1. Нажмите «📄 JSON» на панели инструментов
2. Редактируйте JSON в текстовом поле
3. Статус валидации: зелёный — OK, красный — ошибка
4. **«Применить»** — применить изменения
5. **«Сбросить»** — вернуть к текущему состоянию

## Управление связями

### ConnectionManagerWindow

Открывается кнопкой «Менеджер связей» на панели инструментов редактора.

- Таблица всех связей с колонками: №, Имя, Тип, Зона-A, Зона-B, Guard, Road
- Двойной клик по строке — открыть ConnectionSettingsWindow
- Кнопка удаления связи
- Fan-out рёбер — автоматическое распределение линий для наглядности
- Не-модальное окно — можно редактировать одновременно с основным редактором

### ConnectionSettingsWindow

Открывается двойным кликом из менеджера связей.

- Редактирование всех параметров связи
- Расширенная секция (Guard Match Group, Sim Turn Squad)
- Автоматическая валидация уникальности имени

| Тип | Примеры |
|-----|---------|
| **Предметы** | random_item_common, random_item_rare, random_item_epic, random_item_legendary |

| **Банки существ** | random_unit_bank (T2–T5) |
| **Банки ресурсов** | random_res_bank (T2–T5) |

### Уровни контента (Tiers)

| Tier | Тип зоны | Сложность |
|------|----------|-----------|
| T2 | Side zones, Bronze | Низкая |
| T3 | Treasure zones, Silver | Средняя |
| T4 | Super treasure, Gold | Высокая |

### Создание пула контента

1. Перейдите на вкладку «Content Pools» в главном окне
2. Нажмите «➕ Создать новый пул»
3. Выберите списки контента из доступных категорий
4. Настройте веса и биомные ограничения
5. Экспортируйте пул в JSON

### Просмотр пулов

- Выберите пул из выпадающего списка
- Таблица показывает: SID объекта, категорию, Tier, тип, описание
- Статистика: количество групп, объектов, общий вес
- Недостающие списки подсвечиваются красным

## Часто задаваемые вопросы

### Как создать простой 1v1 шаблон?

1. Откройте программу
2. На вкладке Simple Mode выберите Game Type = Duel
3. Нажмите «Сгенерировать»
4. Шаблон откроется в визуальном редакторе
5. При необходимости отредактируйте зоны и связи
6. Нажмите «Сохранить»

### Как импортировать HotA .h3t шаблон?

1. В главном окне нажмите «Импорт H3T»
2. Выберите .h3t файл
3. Программа сконвертирует его в .rmg.json и откроет в редакторе

### Как сделать симметричную карту?

1. Откройте визуальный редактор
2. Создайте базовые зоны для одной половины
3. Нажмите «Зеркало» и включите зеркальное создание
4. Продолжайте редактировать — зоны будут дублироваться автоматически

### Как добавить свой город в зону?

1. Выберите зону в редакторе
2. В инспекторе найдите секцию «Main Objects»
3. Измените тип на «City»
4. Настройте фракцию, владельца, охрану
5. В секции «Additional Main Objects» можно добавить больше городов

### Как настроить дороги между зонами?

1. Создайте связь между зонами
2. В инспекторе связи включите флаг «Road» (или выберите тип Direct)
3. Дороги на карте будут соединять главные объекты зон

### Как поделиться шаблоном с другом?

- **Simple Mode**: просто передайте сид (число в названии шаблона)
- **Advanced**: сохраните шаблон в .rmg.json и передайте файл
- **Пресеты**: встроены в программу, не требуют передачи

### Почему карта не генерируется в игре?

Проверьте:
1. Правильный ли формат JSON (используйте JSON Preview для проверки)
2. Все ли зоны имеют уникальные имена
3. Нет ли изолированных зон (без связей)
4. Не превышен ли лимит зон (максимум 32)
5. Достаточно ли места на карте для всех зон
