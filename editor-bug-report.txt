1. ОПИСАНИЕ ПРОБЛЕМЫ
================================================================================

Кнопка "Редактор" (BtnEditor) в главном окне открывает визуальный редактор зон
(TemplateEditorWindow). В этом редакторе пользователь может выбрать зону или
связь и отредактировать их свойства в инспекторе (InspectorFields).

ОШИБКА 1: данные, введённые в текстовые поля инспектора, НЕ СОХРАНЯЮТСЯ при
нажатии кнопки "Сохранить .rmg.json" (BtnSave), если пользователь не нажал
Enter и не переключил фокус с поля ввода перед сохранением.

ОШИБКА 2: в поле "Раскладка (layout)" не отображается тип выбранной зоны.

ОШИБКА 3: в инспекторе отображаются только часть параметров зон и связей,
многие редактируемые поля модели отсутствуют.

2. КОРНЕВЫЕ ПРИЧИНЫ И ИСПРАВЛЕНИЯ
================================================================================

ОШИБКА 1: Нет принудительного коммита при сохранении/загрузке
--------------------------------------------------------------------------------
Файл: TemplateEditorWindow.xaml.cs

Методы AddTextField() и AddComboField() записывают значения в модель только по
событиям LostFocus и Enter/SelectionChanged. При клике на кнопку "Сохранить"
событие LostFocus не успевает сработать до начала сериализации.

Исправление: добавлен Keyboard.ClearFocus() в начало BtnSave_Click() и
BtnLoad_Click() — принудительно вызывает потерю фокуса и записывает все
несохранённые значения в модель перед сериализацией/загрузкой.

ОШИБКА 2: ComboBox не устанавливает SelectedItem
--------------------------------------------------------------------------------
Файл: TemplateEditorWindow.xaml.cs, метод AddComboField()

Устанавливался только combo.Text = value, но не combo.SelectedItem. В WPF при
IsEditable = установка Text не гарантирует, что элемент будет визуально отмечен
как выбранный.

Исправление: добавлена строка:
    if (value is not null && combo.Items.Contains(value))
        combo.SelectedItem = value;

ОШИБКА 3: В инспекторе отсутствуют многие параметры моделей Zone и Connection
--------------------------------------------------------------------------------
Файл: TemplateEditorWindow.xaml.cs, метод BuildInspector()

Зона (Zone) имела только 6 редактируемых полей из ~20+ сериализуемых.
Связь (Connection) имела только 5 из ~12 сериализуемых.

Исправление: расширен BuildInspector() для редактирования ВСЕХ параметров:

  Зона — добавлены:
    - guardCutoffValue (Порог охраны)
    - guardRandomization (Рандомизация охраны)
    - guardWeeklyIncrement (Еженедельный прирост охраны)
    - guardReactionDistribution (Распределение реакции охраны) — список int
    - encounterHolesSettings.affectedEncounters (Затронутые столкновения)
    - encounterHolesSettings.twoHoleEncounters (Двухдырочные столкновения)
    - guardedContentPool (Гарантированный пул) — список строк
    - unguardedContentPool (Негарантированный пул) — список строк
    - resourcesContentPool (Пул ресурсов) — список строк
    - mandatoryContent (Обязательный контент) — список строк
    - contentCountLimits (Лимиты количества контента) — список строк
    - guardedContentValue (Ценность гарантированного)
    - guardedContentValuePerArea (Ценность гарантир. на область)
    - unguardedContentValue (Ценность негарантированного)
    - unguardedContentValuePerArea (Ценность негарант. на область)
    - resourcesValue (Ценность ресурсов)
    - resourcesValuePerArea (Ценность ресурсов на область)
    - crossroadsPosition (Позиция перекрёстка)
    - zoneBiome (Биом зоны) — BiomeSelector с подполями type и args
    - contentBiome (Биом контента) — BiomeSelector
    - metaObjectsBiome (Биом мета-объектов) — BiomeSelector
    - roads (Дороги) — список Road с подполями type, from, to

  Связь — добавлены:
    - name (Имя связи)
    - guardWeeklyIncrement (Еженедельный прирост охраны)
    - guardZone (Зона охраны)
    - guardEscape (Охрана может сбежать) — чекбокс
    - simTurnSquad (Одновременный отряд) — чекбокс
    - gatePlacement (Размещение ворот)
    - length (Длина)

Добавлены новые методы-помощники для сложных типов:
    - AddStringListField() — редактирование List<string> (через запятую или с новой строки)
    - AddIntListField() — редактирование List<int>
    - AddBiomeSelector() — редактирование BiomeSelector (type + args)
    - AddRoadList() — редактирование List<Road> (формат: [0] type=Dirt, from=Connection:arg, to=MainObject:arg)

Добавлены 38 новых строк локализации (RU + EN) для всех новых полей.
